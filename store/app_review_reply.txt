3. WHAT THE APP DOES AND WHO IT IS FOR
Language Through Travel teaches travel phrases in the order a trip actually needs them: airport, hotel, restaurant, taxi. The interface is in Vietnamese and the app teaches four target languages: English, Japanese, Korean and Thai.

The problem it solves: phrasebooks are organised like dictionaries, so travellers look a sentence up, use it once and forget it. This app pairs every phrase with a spaced-repetition schedule, so what you study before departure is still available on arrival.

Target audience: Vietnamese speakers preparing for a trip abroad, roughly ages 18-55, from complete beginners to lower-intermediate learners. It is not aimed at children and contains no age-restricted content.

Value: 192 phrases and dialogues written for real situations, offline pronunciation, a searchable phrasebook, four practice games, and a reference guide covering emergencies, numbers, money, directions and etiquette.

4. SETUP AND HOW TO REACH EVERY FEATURE
No account, no login and no demo credentials are required. No sample files are needed. Install and open.

On first launch the app asks which language you want to learn. Pick any one; all four are fully populated.

IMPORTANT, so nothing looks broken: the four journey stages unlock in sequence. Only "Sân bay" (Airport) is open at the start. A stage unlocks once the previous one reaches 50 percent, which means opening 6 of its 12 phrases in the Flashcard screen and rating each one. Tapping a locked stage shows an explanatory message; this is intended behaviour, not an error.

The five bottom tabs, left to right:
- Hành trình (Journey): the four stages, daily goal, streak.
- Sổ tay (Phrasebook): every phrase, searchable and filterable, with a star for favourites. Nothing is locked here, so this tab is the fastest way to see the full content.
- Luyện tập (Practice): the review session plus four games. Games need at least 4-6 phrases in the selected pool; choose the "Tất cả" (All) pool to play immediately.
- Cẩm nang (Guide): six reference topics, all unlocked.
- Tiến độ (Progress): statistics, badges and settings.

The speaker icon uses the system text-to-speech voice. If the test device has no installed voice for the selected language, iOS returns nothing and the app stays silent rather than showing an error. Thai and Korean voices are often absent by default. Installing a voice under Settings > Accessibility > Spoken Content > Voices makes it audible. English is available on every device, so we suggest reviewing with English selected.

5. EXTERNAL SERVICES, TOOLS AND PLATFORMS
None. The app makes no network requests of any kind. It has no backend, no analytics, no advertising SDK, no authentication provider, no payment processor and no AI or machine-learning service. All learning content is bundled inside the binary as static Dart files and is available with the device in Airplane Mode.

The only system service used is Apple's on-device speech synthesiser (AVSpeechSynthesizer), reached through the open-source Flutter plugin flutter_tts, and only when the user taps a speaker button. No text is sent anywhere by the app itself.

Third-party open-source packages: provider (state management), shared_preferences (local key-value storage), flutter_tts (system speech). All progress is stored locally via shared_preferences and never leaves the device. Nothing is collected, so the privacy questionnaire is set to "Data Not Collected".
